# 侧边栏页面交互审查

日期：2026-07-23

## 范围

桌面端总览、资产、流水、规划、提醒与 AI 管家，以及移动端提醒事项录入。

## 结论

原型原有的部分主操作已经绑定状态，但通用操作弹窗缺少完整布局样式，实际打开后表单会挤成一行；各页面的语音入口也共用资产交易示例，无法反映当前页面的输入意图。现已修复弹窗布局、补充流水录入，并让语音解析随页面切换。

## 流程步骤

1. 总览入口 — 健康：良好。桌面端保留右下角上下文语音入口，移动端保留底部中央语音入口。
2. 资产 → 添加账户 — 健康：已修复。支持手动录入、文件导入和连接数据源；手动录入会保存到账户草稿。
3. 流水 → 添加流水 — 健康：已补齐。支持收入、支出、转账和投资交易的手动录入，并先进入待对账区。
4. 流水 → 语音输入 → 解析核对 — 健康：良好。示例、解析结果和确认动作与流水页面一致。
5. 提醒 → 添加事项 — 健康：已修复。页面与弹窗统一使用“事项”，可选同时创建提醒，不生成或发送催租文案。
6. 提醒 → 语音输入 → 解析核对 — 健康：良好。解析结果为保险续缴事项及提醒时间。
7. AI 管家 — 健康：良好。桌面端不重复显示页面级悬浮语音按钮。
8. 移动端提醒 → 添加事项 — 健康：良好。单列弹窗在 390px 宽度下完整可用，底部操作按钮没有被遮挡。
