# Folio 微信小程序原生壳

这是 M0 架构验证工程，不是已上线产品。它刻意保持无 npm 运行依赖、无客户端密钥、无真实财务数据，用于验证：

- 微信原生 WXML/JS 页面骨架；
- Canvas 2D 在财务趋势图场景中的基础能力；
- 与 React 19 桌面端解耦的运行时边界；
- 后续通过 Folio BFF 接入共享契约，不直连模型或数据库。
- M1 已实现原生 WXML/JS 只读产品壳：解锁占位、总览、资产、流水、统一采集、提醒、AI 管家和设置。
- 所有 M1 数据均是明确标记的虚构演示数据，交互不会写入账本。
- DeepSeek 测试链路只会通过 `services/folio-bff` 在服务端读取环境凭证；小程序包中不含凭证。

开发者工具中直接导入本目录。当前使用 `touristappid` 仅供结构验证；M1 实机测试前必须换成人工注册的 AppID，并由微信后台授权开发者与体验成员。
