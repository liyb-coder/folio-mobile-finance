# M4 AI 与真实数据采集实施状态

更新：2026-07-27

## 已落地

- 本地 `local_rules_v1` 中文财务提案解析器，支持中文金额、相对/中文日期、账户别名和机构简称。
- 可生成四类结构化提案：
  - 账户：机构、名称、类型、期初余额和余额日期。
  - 流水：收入、支出、同币种转账、账户、金额、日期和分类。
  - 事项：标题、类型、日期、可选金额、提前提醒和关联账户。
  - 规划：现金安全垫和现金、稳健、权益、黄金、保险、其他六类精确目标。
  - 产品操作：唯一有效持仓、申购/赎回/分红/费用、操作金额、可选结算账户；申购/赎回还要求原话明确操作后份额、累计成本和当前市值。
- 设置、数据源和未建模动作默认拒绝，不把未知动作伪装成普通流水、账户余额或产品操作。
- 规划档案使用 SQLCipher 保存，配置目标必须精确合计 100%；手工和口述修改都经过草稿、最终核对和明确确认。
- 每次规划创建或更新都追加不可修改的 `planning_events`，并在确认时重新核对版本，拒绝并发过期草稿。
- 规划页的试算沙盘只存在于页面内存，不连接确认命令，不创建草稿，也不改变余额或账本。
- 除 AI 管家外的本地桌面模块保留右下角上下文语音入口；AI 管家使用页面内的主输入入口。
- 输入页支持直接文字；macOS/iOS 原生端接通 Apple 设备内语音识别。每次调用前必须勾选同意，强制离线模型且不保存原始音频；离线识别不可用时不联网降级。
- Apple 端支持从同一输入页选择 PNG/JPEG/HEIC/TIFF、可选中文本 PDF 或扫描 PDF；PDFKit 逐页提取/渲染，Vision 完全在设备内 OCR，不调用外部服务。
- 扫描 PDF 页面先规范化为最长边 1800 像素的 RGBA 位图，单页处理后立即释放；界面显示 OCR 页数与未识别页数，部分结果不能伪装成完整文件。
- 文档原件、完整路径和二进制不进入 React、数据库、日志或同步；只返回文件名、SHA-256、页数、受限文字和页码/范围/置信度/图片坐标证据。
- 文件文字仍复用 `local_rules_v1`，并沿用“提案核对 → 原生草稿 → 明确确认”链路；手动编辑提取文字会解除文件证据关联。
- 提案核对页展示原文、字段值、逐字段置信度、警告和未决项。未决项存在时不能生成领域草稿。
- 领域草稿由原生账户、产品操作、流水、事项或规划命令重新校验；最终页面只显示原生命令返回的精确值。
- 只有“明确确认并写入”调用领域确认命令；关闭或取消会拒绝待核对草稿。
- SQLCipher 新增不可变 `ai_proposals`，保存提案原文、哈希、提供器、解析器版本、置信度和证据，并一对一绑定待核对领域草稿。
- AI 提案审计不复制原文；当前口述证据不进入云同步。
- AI 管家升级为 `local_ledger_qa_v2` 只读问答，支持：
  - 账户余额和基础币种账户总余额。
  - 今日/本月或全部未冲销收入、支出。
  - 最近五笔未冲销流水。
  - 最近五项待处理事项。
- 新增本月与上月收入、支出和净现金流比较，支出分类排行、金额最大支出和基础币种现金流解释。
- 聚合回答展示指标卡、完整来源笔数、可见引用覆盖率和逐事件时间；转账、其他币种、已冲销事件不会混入收支解释。
- “大额支出”只按金额排序，并明确声明不会擅自判定异常或欺诈。
- 每个回答返回对象类型、来源 ID、摘要、数据时间和计算时间；没有引用时明确提示不会编造事实。
- 问答拒绝收益预测、买卖建议和未覆盖问题；问题与回答只保留在当前解锁页面状态，不写 SQLCipher 或同步。
- 统一 `ModelProvider` 注册表声明设备内/外部数据边界和能力；默认只有 `folio_local_v1`，外部提供器在本次调用未显式授权时不会执行。

## 安全不变量

1. 本地解析器不持有账本仓库或原生确认能力。
2. `ai_proposal_record` 只能绑定匹配类型、状态为 `needs_review` 的领域草稿。
3. 记录提案不能确认草稿、创建账户、追加流水、改变事项或规划。
4. 正式变化仍必须由用户在原生最终核对页明确确认。
5. 不支持、低置信度或缺关键字段的输入不能跳过核对。
6. 本地账本问答没有 repository 或原生命令句柄，不能创建任何草稿或正式事件。
7. 文件选择前后都要求保险库已解锁；原件和完整路径不能进入提案证据。
