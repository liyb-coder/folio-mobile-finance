# Folio 移动优先 MVP 界面检查

日期：2026-07-29
视口：移动端 390 × 844；Mac 回归 1280 × 720

## 结论

移动端已经从“桌面仪表盘的窄屏版”调整为“快速录入工具”。冷启动、AI 录入、密码入口、资产、提醒和 AI 问答均保持同一套灰紫 / 炭黑 / 荧光绿视觉语言，同时减少了重复状态卡、流程说明和大段安全文案。

## 流程步骤

1. 密码入口 — 健康
   - 标题和说明缩短；密码仍是必备路径，Touch ID 是可选便利入口。
   - Logo、密码显示按钮、解锁和备份恢复入口可见。
   - 证据：`09-mobile-password-final.png`

2. 无数据冷启动 — 健康
   - 首屏优先展示“先说一段”和“导入资料”。
   - 去掉重复三步流程卡；手动添加账户保留为次级入口。
   - 证据：`06-mobile-empty-overview-final.png`

3. 统一 AI 录入 — 健康
   - 语音、截图/文档、文字是同一个弹窗内的三个明确入口。
   - 安全提示压缩为“先核对，再写入”；录入按钮单排展示。
   - 证据：`07-mobile-capture-final.png`

4. 截图 / 文档模式 — 健康
   - 明确支持图片、PDF、Markdown 和纯文本。
   - 冷启动“导入资料”能直接打开该模式。
   - 证据：`08-mobile-document-mode-final.png`

5. 资产页 — 健康
   - 三个摘要指标从纵向大卡改为同一行小卡。
   - 标题说明缩短，账户卡提前进入首屏。
   - 证据：`15-mobile-assets-final.png`

6. 提醒页 — 健康
   - 主动作保持“添加事项”。
   - 删除催收相关解释，摘要指标压缩为一行。
   - 证据：`16-mobile-reminders-final.png`

7. AI 管家 — 健康
   - 只读边界改成一句话；隐藏内部提供器名称。
   - 写入入口缩短为“录入新信息 / 语音、截图或文字”。
   - 证据：`14-mobile-assistant-final.png`

8. Mac 共用界面回归 — 健康
   - 桌面两栏总览、侧栏、账户卡和语音入口均正常。
   - 移动端摘要压缩规则没有影响桌面布局。
   - 证据：`17-desktop-overview-regression.png`

## 仍需设备验证

- 截图只能验证可见结构，不能证明真机麦克风、系统文件选择器、相册权限和后台锁定行为。
- iOS / Android 原生工程尚未完成工具链与真机验收。
- Gmail OAuth 和邮件拉取尚未实现；当前只完成产品/技术边界和里程碑定义。
