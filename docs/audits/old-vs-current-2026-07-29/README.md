# Folio 旧版与当前版视觉核对

核对基线：

- 旧版：Git `HEAD`（`b50e713`），临时运行于 `http://127.0.0.1:4173/?vault-preview=analytics`
- 当前版：工作区未提交版本，运行于 `http://127.0.0.1:5173/?vault-preview=analytics`
- 桌面端统一为 1280 × 720，移动端统一为 390 × 844

## 1. 桌面总览

证据：`01-old-desktop.png`、`02-current-desktop.png`

健康度：基本稳定。主卡、侧栏、账户卡和语音入口仍然延续原有设计。当前版的主要变化集中在品牌资源和少量状态信息，不是“越改越丑”的主要来源。

## 2. 移动总览

证据：`03-old-mobile.png`、`04-current-mobile.png`

健康度：明显退化。

- 旧版的保险库状态卡把主资产卡与账户卡连接起来，形成清楚的纵向节奏。
- 当前版删除该层后，仅剩两张偏小的账户卡，随后出现大面积空白。
- 信息虽然更少，但视觉重心失衡，安全感与产品个性也一起被削弱。
- 当前版底部“AI 录入”命名比旧版“记一笔”更准确，但不应以牺牲页面完整度为代价。

## 结论

后续应以旧版移动总览为视觉骨架，保留它的密度、圆角卡片层级和安全状态表达；把当前版的 AI 统一录入、密码锁图标、Markdown/文档导入等能力逐项接回，而不是继续做整体减法。
