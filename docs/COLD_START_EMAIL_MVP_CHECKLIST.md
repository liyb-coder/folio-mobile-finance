# Folio 冷启动与 QQ 邮箱 MVP 清单

更新日期：2026-07-30

## 当前结论

以下核心链路已实现并自动化通过：

- 从空 SQLCipher 保险库导入 `docs/demo/Folio_冷启动全量演示数据.md`；
- 本机确定性拆分账户、持仓、流水、事项和规划；
- 按账户 → 持仓 → 流水 → 事项 → 规划分组核对；
- 未确认前不写领域数据或账本；
- 44 个草稿确认后得到精确净资产 `2,214,732.17`；
- QQ 邮箱通过 IMAPS 只读获取，先查邮件头白名单再取正文；
- 单封邮件可拆分多笔信用卡消费；
- 授权码只进 Keychain，正文不落库；
- 邮件记录只生成待核对流水，重复消息不会二次生成。

## 当前数据边界

```text
QQ 邮箱
  → IMAPS / EXAMINE
  → 新 UID
  → From + Subject 白名单
  → 临时正文
  → 本地确定性解析
  → SQLCipher 待核对草稿
  → 用户逐笔确认
  → 不可变账本
```

任何网络、解析、映射、金额、日期、币种或重复性不确定，都必须停在“隔离/需补充”，不得直接写账。
