# Folio 产品方案与路线图

> 版本：1.0  
> 更新：2026-07-30  
> 范围原则：先保证输入可信、账本准确，再扩展分析和连接能力。

## 1. 产品结构

| 模块 | 用户要解决的问题 | 第一期形态 |
|---|---|---|
| 总览 | 我有多少钱，今天要处理什么 | 总资产、活期可用、近期变化、重要提醒 |
| 资产 | 钱分别在哪里 | 账户、余额、简单资产明细 |
| 流水 | 最近发生了什么 | 收入、支出、转账、信用卡消费 |
| 提醒 | 什么时候要行动 | 租金、保险、到期、还款 |
| AI 收件箱 | 输入是否识别正确 | 待核对、需补充、疑似重复、已确认 |
| 设置与安全 | 数据和模型如何管理 | 密码、备份、QQ 邮箱、AI 提供器 |

## 2. 第一期：可靠记录 MVP

### 目标

跑通“输入 → 待核对 → 明确确认 → 账本/提醒更新”的最小闭环。

### 功能清单

- 本地保险库、应用密码、自动锁定和加密备份；
- 人民币单币种账户与流水；
- 收入、支出、转账的新增、修改和可追溯更正；
- 文字、语音、截图、PDF、Markdown 输入；
- 一次输入可拆为多条待核对项；
- QQ 邮箱信用卡消费邮件的只读、白名单和增量拉取；
- 邮件去重、退款/撤销标记和多笔消费拆分；
- 租金、保险、到期、还款四类提醒；
- 移动端主入口和 macOS 批量核对/备份入口。

### 首期用户路径

**首次使用**

1. 设置应用密码；
2. 新建或导入基础账户；
3. 核对初始余额；
4. 可选连接 QQ 邮箱；
5. 设置第一条提醒；
6. 完成加密备份。

**日常语音记录**

1. 点击底部中央录入；
2. 在设备上完成语音转文字；
3. 解析成结构化草稿；
4. 用户检查账户、方向、金额和日期；
5. 明确确认后写入账本。

**信用卡邮件记录**

1. 邮箱连接器只读取允许的发件人/文件夹；
2. 邮件进入收件箱并去重；
3. 模板解析为一条或多条待核对消费；
4. 用户补齐信用卡账户或商户分类；
5. 确认后才写入流水。

### 一期退出标准

- 一周日常使用中没有确认前入账；
- 重复邮件与重复文件不会产生重复正式流水；
- 汇总金额与已确认明细一致；
- 语音、截图、PDF 和邮件失败时能说明原因并允许手工补充；
- iPhone 与 macOS 真实设备完成解锁、录入、确认、提醒、备份恢复验收。

## 3. 第二期：丰富数据与资产理解

在一期稳定后增加：

- Android 真实设备支持；
- CSV/TSV/XLSX、飞书表格/多维表格导入；
- 更多 QQ 邮箱和银行通知模板；
- 保险保单、基金/理财持仓的结构化提取；
- 产品表现、持仓变化和数据质量检查；
- 更高效的批量核对、合并与分类；
- 可选的加密跨设备同步试运行。

第二期仍不允许 AI 自动入账或自动调仓。

## 4. 第三期：分析、市场与规划

在真实账本稳定且有足够历史数据后增加：

- 多币种、汇率来源和未折算口径；
- 市场行情与产品穿透信息；
- 资产配置诊断与解释型 AI 建议；
- 与真实账本明确隔离的投资组合模拟沙盘；
- 正式加密跨设备同步；
- 可选家庭视图和机构连接器。

任何市场建议只形成“建议卡片”，不会直接形成交易或修改持仓。

## 5. 建议开发节奏

| 阶段 | 建议时间 | 交付结果 |
|---|---:|---|
| A. 移动技术验证 | 1 周 | iPhone 真机解锁、离线语音、选图/PDF、通知、后台锁定 |
| B. AI 收件箱 | 2–3 周 | 多来源待核对列表、多记录拆分、明确确认 |
| C. QQ 邮箱 | 2 周 | 只读授权、白名单、增量同步、去重和模板解析 |
| D. 一期联调 | 2 周 | 人民币账本、提醒、备份与真实数据副本验收 |
| E. 私人测试 | 2–4 周 | 连续使用、错误统计、模板补强和发布门 |

时间是规划量级，不是发布日期承诺。每一阶段都以真实设备和可追溯测试证据结束。

## 6. 一期准备清单

- 一台用于开发和真机测试的 iPhone、Apple 开发工具链；
- 一个专门测试用的 QQ 邮箱和若干脱敏信用卡邮件样本；
- 10–20 条虚构语音、截图、PDF、Markdown 测试样本；
- 账户、流水、提醒的字段确认；
- AI 服务测试账号和限额；
- 隐私说明、邮箱读取说明、数据删除与备份说明；
- 一份只保存在本地的代表性真实数据副本，用于最终验收。

## 7. 延后但保留的需求

闲置活期提醒、产品表现、AI 调仓和模拟沙盘仍在产品蓝图中，但不应挤占一期的准确录入、去重、确认和恢复能力。
