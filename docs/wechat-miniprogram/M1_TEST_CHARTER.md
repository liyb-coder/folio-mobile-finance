# M1 测试章程：只读产品壳

日期：2026-08-11  
状态：Green（自动化完成，微信开发者工具视觉验收待补）

## 用户结果

用户可以在微信原生壳中查看与 Folio 移动视觉源一致的总览、资产、流水、提醒、AI 管家和设置，并从持久底部导航进入统一采集。M1 只使用明确标识的虚构数据，不尝试登录、录音、网络请求或账本写入。

## 必须通过

1. App 注册解锁/演示入口、总览、资产、流水、采集、提醒、AI 管家和设置页。
2. 自定义 tabBar 保留总览、资产、居中采集、提醒和 AI 管家，居中行为与移动视觉源一致。
3. 所有主页使用共享 Folio 顶栏，设置和流水通过菜单可达。
4. fixture 必须标记 `fictional: true`，对象深度冻结，不使用真实客户数据。
5. 总览、资产和提醒页面的卡片层级、配色、圆角和信息密度对齐 `folio-v2-mobile*.png`。
6. 采集页的语音/截图/文字入口可点击，但 M1 只显示“下一里程碑接入”，不申请权限。
7. 源码不得出现 `wx.request`、`wx.uploadFile`、`wx.getRecorderManager`、账本写入或任何凭证字段。
8. 所有可见图标使用已选品牌资产或 Phosphor 图标库导出的 PNG，不使用文字符号或 CSS 伪图标。

## 对抗角色

- 误把演示数据当真实数据的客户；
- 连续快速点击导航和采集入口的用户；
- 试图在只读里程碑发起录音或写入的误操作；
- 被删除缓存、前后台切换和低端设备影响的用户；
- 检查客户端包中密钥、真实数据和隐藏网络请求的审核者。
