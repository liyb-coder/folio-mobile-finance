# M0 测试章程：架构与契约基线

日期：2026-08-11  
状态：自动化通过；开发者工具/真机证据待人工补齐

## 范围

- 小程序客户端不携带服务端密钥；
- 平台能力端口不完整时 fail closed；
- 语音、图片和文件结果只能成为 `pending_review` 提案；
- 证据必须回指本次来源，不允许夹带服务端写入状态；
- 确认操作必须包含显式意图、预期版本、幂等键和非空项目集；
- 原生微信壳必须无 WebView、无真实数据、无未使用录音权限、无 npm 运行依赖；
- M0 源码不得超过 200KB 预算。

## 测试方法

1. 先写 6 组契约测试，确认共享包缺失时为红；
2. 实现最小 `folio-contracts`，转绿；
3. 以恶意客户端角色补充循环配置、伪造证据、可变坐标、伪执行状态测试；
4. 先写 3 组原生壳测试，确认工程不存在时为红；
5. 实现旅客模式原生壳、Canvas 验证页和包体预算，转绿；
6. 运行根回归测试，确认现有 macOS/Web 功能未回归。
