# M2a 测试章程：文字采集到待核对提案

更新：2026-08-12

## 范围

M2a 只打通以下链路：

`小程序文字输入 → HTTPS/本机开发 BFF → DeepSeek 语义整理 → 精确证据校验 → pending_review 卡片`

不包含微信身份绑定、真实账本写入、语音 ASR、图片 OCR、订阅消息和跨端同步。确认按钮保持不可用，直到 M2b 的身份、版本检查、前台重新验证和防重放服务完成。

## 前置测试

1. 输入页不再使用占位 Toast；
2. 客户端请求体只允许 `sourceId`、`sourceKind` 和 `text`；
3. 客户端包不含模型密钥或供应商凭证；
4. 远端只允许 HTTPS，本机开发允许 loopback HTTP；
5. 返回值必须为 `pending_review`；
6. 每个项目必须引用这次输入中的连续原文；
7. 服务端声称“已写入/已确认”时客户端拒绝；
8. 网络失败不保存为成功，也不清空原输入；
9. 核对卡展示整理结果和原话证据；
10. 没有身份联调前不得提供可点击的写账捷径。
