# M3 身份与可选同步实施状态

更新：2026-07-27

## 已落地

- `sync` 运行模式的 Web 身份门：邮箱密码登录、创建账户、退出本机会话、统一错误提示。
- macOS 安全设置已提供原生同步控制台：云端身份登录/注册、明确确认启用、立即同步、待上传/冲突状态、明确停止同步和退出内存会话；未配置云服务时保持纯本地并给出可恢复提示。
- Web Auth 会话不持久化到浏览器存储；默认数据模式和 Tauri 本地保险库不依赖云身份。
- Web 未配置时默认进入 `locked`，不加载任何财务组件；浏览器 `local` 模式安全拒绝，不会误回退到 Demo。
- 公开 Demo 需要显式非密钥开关和访问者确认，并在进入后持续显示“公开虚构演示”横幅。
- 已认证 Web 页面连续 15 分钟无活动时先本地退出并卸载私人界面，再尽力撤销 Supabase 会话；远端失败不恢复 UI。
- Supabase 通行密钥实验 API 已放在独立功能开关后，锁定 `@supabase/supabase-js 2.105.0`。
- 客户端事件加密使用锁定版本 `@noble/ciphers 2.2.0` 的 XChaCha20-Poly1305。
- AAD v2 将事件种类、vault、device、event、逻辑时钟、幂等键、时间和前序哈希共同绑定；随机 nonce、事件哈希和设备内连续哈希链共同约束密文事件。
- 离线队列只接受密文 envelope，重复事件安全复用，标识/哈希碰撞转入核对。
- Tauri 原生层生成 X25519 设备密钥对，并通过 HKDF-SHA256 + XChaCha20-Poly1305 包装保险库同步密钥；私钥和同步密钥不进入 React。
- 本地账户/持仓资料快照、不可变持仓估值、账本事件、产品操作、补偿更正和提醒快照均可增量转换为不可变 `sync_outbox_events`；名称、金额、数量、市值、正文与备注不进入明文 envelope，投递状态与追加式重试/成功/冲突审计分离。
- 远端页面进入原生层后，会重新计算 AAD + nonce + ciphertext 的 SHA-256、执行 XChaCha20-Poly1305 认证解密、检查每台设备的逻辑时钟前序哈希，并先写不可变 inbox 再原子应用到 SQLCipher。
- 第二设备可按账户 → 持仓 → 估值 → 账本 → 产品操作 → 补偿更正 → 提醒的依赖顺序重建本地数据；重复页面、重复事件和已有相同内容均幂等处理。
- 入站应用审计同时作为回声抑制标记：第二设备恢复的数据不会自动重新进入 outbox，只有该设备之后明确确认的新修改才生成新事件。
- 不同设备修改同一账户、持仓资料或提醒时不使用静默 last-write-wins；不可变估值/操作发生标识碰撞或引用缺失时同样安全隔离，本机确认版本保留，且不会产生草稿或业务半成品。
- 本机同步冲突可列出未处理项与历史；打开详情会从不可变 inbox 重建 envelope 并重新验证哈希、AAD 和认证密文，成功后只向 UI 返回必要领域字段，不返回 nonce、ciphertext 或同步密钥。
- 用户必须二次勾选才能“明确保留本机版本”。原始密文与冲突证据保持不可变，单独追加 `keep_local` 解决记录和 `conflict_resolved` 审计；本机业务记录不被改写。采用远端保持关闭，直至能映射为领域核对草稿。
- 已登记设备可在身份会话和本机 `cloudVaultId` 作用域内只读查看；仅返回平台、时间、状态和不透明设备 ID。设备撤销尚未开放，避免在缺少近期重新认证和同步密钥轮换时造成不可恢复状态。
- 云端首次创建使用 `SECURITY INVOKER` 原子 RPC，一次写入 vault、owner membership、device 与首个 device key envelope；相同密文 bootstrap 可安全重试。
- 原生启用流程先在 SQLCipher 安装设备配置，再执行幂等远端 bootstrap；若远端初始化失败，会立即把本机同步回滚为关闭并保留原始错误供重试，避免 UI 显示已启用但云端尚未建立。
- 关闭同步只停止队列准备，不影响本地账本；从备份恢复的新保险库会清除旧云绑定与设备身份。
- Supabase 迁移覆盖 profile、vault、membership、device、设备密钥 envelope、完整账户/持仓/账本/事项密文领域事件、冲突、冲突解决和附件 manifest；持仓升级迁移只扩展不透明 `event_kind` 约束，不新增财务明文字段或权限。
- 所有 Folio `public` 表启用并强制 RLS；`anon` 权限撤销；`encrypted_sync_events` 对客户端保持追加式。
- `folio-private` bucket 固定为私有、10 MB 上限，路径同时限制当前用户和活跃 vault membership。

- JavaScript/领域/安全测试：189 项通过（包含原生同步身份/明确确认/失败回滚/敏感信息边界、本机冲突决议、最小设备状态、macOS DMG 发布门与 MVP 体检、完整持仓密文事件白名单、Supabase 升级约束、产品补偿式冲销、资产语音证据、Web 锁定、移动 readiness、同步与后续里程碑回归）。
- Rust/SQLCipher/备份/原生同步测试：84 项通过；另 1 项 Apple Vision 集成测试在沙箱外真实运行时通过（包含完整持仓重建、回声抑制、缺依赖零部分写入、旧库迁移、产品操作原子确认/补偿、AI 产品草稿绑定、备份与导出回归）。
- Vite + Sites 构建通过，生成 `dist/client/index.html`、`dist/server/index.js` 与 `dist/.openai/hosting.json`。
- 浏览器三模式回归：未配置时仅显示锁定页；`local` 明确拒绝普通网页访问原生保险库；公开 Demo 确认前不加载数据、确认后始终显示虚构数据横幅。
- 浏览器 sync 模式：登录前不渲染净资产或金额；密码输入保持隐藏；通行密钥入口受安全来源与功能开关约束；控制台无错误。
- 原生同步设置已在桌面和 390×844 窄屏完成实际点击与无横向溢出验收；冲突详情显示重新验签状态，确认前决议按钮禁用，明确勾选后可保留本机，处理后待办项消失且历史文案保留；没有“接受/采用远端”按钮，浏览器错误日志为空。
- 密文往返、正文不可见、ciphertext/AAD 篡改拒绝、非安全整数拒绝、离线队列幂等均有自动化测试。
- 自动化第二设备演练已覆盖账户、持仓资料、估值、三笔账本事件、两笔产品操作、补偿更正和提醒的完整重建，重复拉取、零回声 outbox、游标推进、哈希篡改拒绝，以及两设备并发编辑不覆盖本机版本。
- 旧版 SQLCipher 同步表迁移测试保留 outbox/inbox、投递/应用状态和实体版本外键，并验证新增事件类型可写；缺少持仓依赖的产品操作会进入 `missing_dependency` 冲突且正式表零写入。
- schema migration 15 已覆盖不可变冲突解决表；自动化测试验证未明确确认时拒绝、重新认证解密后才能查看、处理后未解决计数归零、重复处理幂等且本机账户内容不变。
- macOS release `.app` 已用原生同步设置闭环和受限 Supabase CSP 重新构建；当前为 arm64、约 36 MB、完整 ad-hoc 签名开发包。DMG 为 24,376,576 字节，SHA-256 `1100a1f3a14a7f325a6f3d74148b1f155350cbee90b4d56553806bf539f141c0`。只读挂载发布烟测验证镜像结构、架构、Bundle、最低系统、签名/权限、动态库路径和私有文件排除全部通过，并正确报告 Gatekeeper `not-notarized`；正式分发仍需 Apple Developer 签名与公证。
