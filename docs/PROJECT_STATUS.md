## 不可突破的决策

- 金钱与资料变更始终 parse → review → explicit confirm；语音、文件、AI 和同步冲突都不能直接写正式账本。
- 真实数据、数据库、备份、环境变量和密钥不进入 Git；仓库只提交虚构 fixture。
- 云端只保存认证密文与最小路由元数据；云身份、设备解锁和保险库解密是独立安全层。
- 同步按账户 → 持仓 → 估值 → 账本 → 产品操作 → 补偿更正 → 事项应用，任何缺依赖或语义分歧安全隔离。
- 冲突证据与解决记录不可变。当前只开放明确保留本机；采用远端必须先进入领域草稿。设备撤销必须包含近期重新认证、密钥轮换和其他设备 rewrap。
